**What is PageRank and how can it be adjusted for various applications?**

In this project, we investigated the mathematics behind the revolutionary PageRank
algorithm, beginning with an intuitive look at the algorithm to write it from scratch in MATLAB. 
We then adapt the algorithm for application to building recommendation systems by
reproducing the ItemRank algorithm in MATLAB and applying the results to the MovieLens dataset.

These files are from my 3rd-year dissertation project and may be missing some helpful documentation.
I have tried to organise them in a way that can be explored.
